# 💬 Web Chat Application (Fullstack Realtime Messenger)

Полноценное веб-приложение для обмена сообщениями в реальном времени между пользователями.

## 🚀 Стек технологий

- **Frontend:**
  - React 18 + TypeScript + Vite
  - Tailwind CSS (стильный тёмный интерфейс)
  - Lucide React (иконки)
  - Socket.IO Client (двусторонняя связь в реальном времени)
  - Axios (HTTP API клиент)

- **Backend:**
  - Node.js + Express + TypeScript + TSX
  - Socket.IO Server (события реального времени)
  - Prisma ORM + SQLite (локальная база данных `dev.db`, работает "из коробки" без дополнительных серверов)
  - JWT (JSON Web Tokens) для безопасной аутентификации
  - Bcrypt.js для безопасного хеширования паролей

---

## 🌟 Основные возможности

1. **Регистрация и Вход:**
   - Полноценная аутентификация по логину/email и паролю.
   - Автоматическая генерация уникальных аватаров для каждого пользователя.
   - Защита маршрутов через JWT.
2. **Личные сообщения (1-на-1):**
   - Удобный поиск пользователей по никнейму.
   - Мгновенное открытие и ведение приватного диалога.
3. **Групповые каналы:**
   - Канал по умолчанию `# Общий чат`, в который автоматически попадают все новые пользователи.
   - Возможность создать собственный канал и выбрать нескольких участников.
4. **События реального времени (Socket.IO):**
   - Мгновенная доставка сообщений без перезагрузки страниц.
   - Индикатор статуса: зеленый значок "В сети" / серый "Не в сети" в реальном времени.
   - Индикатор набора текста ("Иван печатает...").
   - Автоматическое обновление списка диалогов при получении нового сообщения.
5. **История сообщений:**
   - Сохранение сообщений в SQLite базе данных.
   - Загрузка истории при переключении между диалогами.
   - Автоматический скролл вниз к свежим сообщениям.
6. **Быстрые реакции (эмодзи):**
   - Встроенная панель популярных эмодзи (👋, 👍, ❤️, 🔥, 😂, 🎉, 🚀, ✨).

## 🛠️ Запуск проекта

### 1. Запуск Сервера (Backend):
В терминале:
```bash
cd server
npm run dev
```
> Бэкенд запустится на: `http://localhost:5000`

### 2. Запуск Клиента (Frontend):
В отдельном окне терминала:
```bash
cd client
npm run dev
```
> Фронтенд будет доступен по адресу: `http://localhost:5173`
